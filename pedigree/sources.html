Sources

Everything this archive stands on, one entry per source. A census page, a deed, a claim file of fifty-odd images and a newspaper notice each count once. 100 of the 148 have a copy here; the rest are cited on the life sheets and still need pulling.

Every source has an ID that will not change, so a note can point at it. Records are labeled the same way as the life sheets. The repository is where the original is kept, not where I found the copy.
